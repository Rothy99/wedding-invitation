# Khmer Custom Fonts Directory (ថតសម្រាប់ដាក់ពុម្ពអក្សរខ្មែរ)

ដាក់ឯកសារពុម្ពអក្សរ .ttf របស់អ្នកនៅក្នុងថតនេះ៖
Place your .ttf font files in this folder:

1. **ពុម្ពអក្សរធម្មតា (Regular Text Font)**:
   - File name: `Kh-Ang-ToaThmor-3.ttf` ឬ `KhAngToaThmor3.ttf`
   - Font family: `Kh Ang ToaThmor 3`

2. **ពុម្ពអក្សរដិត / ចំណងជើង (Bold / Headings Font)**:
   - File name: `Kh-Ang-Moul-Seda.ttf` ឬ `KhAngMoulSeda.ttf`
   - Font family: `Kh Ang Moul Seda`

ប្រព័ន្ធ Web នឹងទាញយកពុម្ពអក្សរពីទីនេះដោយស្វ័យប្រវត្តិដើម្បីបង្ហាញលើទូរស័ព្ទដៃ (iOS & Android) គ្រប់ភ្ញៀវទាំងអស់ទោះបីជាពួកគេមិនទាន់ដំឡើង Font ក្នុងម៉ាស៊ីនក៏ដោយ!
The system will automatically serve these web fonts to all guests on mobile devices (iOS & Android) even if they don't have the fonts installed locally!
